# Freshworks App Workshop

Welcome to the Freshworks App Workshop! This hands-on workshop will guide you through building apps on the Freshworks platform from basics.

We'll start with understanding core concepts of the Freshworks platform, app placement in the UI, and finish with making requests to external APIs.

## Table of Contents

- [Overview](#overview)
- [Workshop Steps](#workshop-steps)
- [Resources](#resources)
- [Community & Support](#community--support)


## Workshop Steps

### Step 1: Getting Started

Set up your development environment and get familiar with the Freshworks ecosystem. [Read more](./step-1/getting_started.md)

### Step 2: Creating Your First App

Build a simple app that displays the requester's name in the Freshdesk ticket sidebar. [Read more](./step-2/README.md)
### Step 3: Using Crayons Components and Instance Methods

Enhance your app with Freshworks Crayons UI components and learn to resize app instances. [Read more](./step-3/README.md)

### Step 4: Multi-Placeholder App

Make your app available across multiple locations in Freshdesk. [Read more](./step-4/README.md)
### Step 5: Specialized Placeholder Content

Create different experiences for Full Page Apps and CTI Global Sidebar placeholders. [Read more](./step-5/README.md)

### Step 6: External API Integration

Build an e-commerce app using the Fake Product AP API to demonstrate external API integration. [Read more](./step-6/README.md)
